# Offendersearch

A commercial REST API (and private-beta MCP server) for nationwide US sex-offender registry screening, searching 58 US registries through one API with scored matches and per-source provenance.

- **Provider:** https://offendersearch.app/
- **Documentation:** https://offendersearch.app/docs
- **Base URL:** https://api.offendersearch.app
- **Tags:** Background screening, Identity & risk, Trust & Safety, Public records, Criminal data, Compliance, Sex-offender registry data, Staffing & recruiting, Tenant screening, Healthcare, Gig marketplaces
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** no
- **Confidence:** 95/100

## APIs

- **Offendersearch API** — REST API for national sex-offender screening; API-key authenticated, JSON responses, synchronous and asynchronous search across all 58 US registries. (`https://api.offendersearch.app`)

> Verified public REST API with live OpenAPI 3.1.0 at /openapi.json (and /openapi.yaml). Auth via X-API-Key header. An MCP server is built and hosted at https://mcp.offendersearch.app but is in PRIVATE BETA (not open to self-serve signups), so it is not cataloged as a reachable MCPServer property; it is documented at the /mcp-server page. LLM-oriented markdown docs (/docs.md, /docs/all.md) exist but a conventional /llms.txt was NOT confirmed, and no published agent skills were found — hence agent_native=false. An agent tool schema is published on the AI-integration page. This provider is distinct from the UK MoJ 'probation-offender-search' repo and vendors offenders.io / offenderlist.us.
